The EN/ZH compact-interface images are genuine Qt widget captures from the
isolated Slicer 5.10 compact-UI smoke test. Initial source:
<code>ignore/validation/push_anatomy_20261011/staged_gui/compact_ui/compact_en_440.png</code>
and <code>compact_zh_440.png</code>; source tree
4993990bf66095c18ea5de2fbb8d3e11f2f777ba, corresponding to main commit 37a543c.

They demonstrate missing-input feedback after clicking Run, not a completed
scientific analysis. Empty input fields contain no patient data/private paths.
Images are copied without generative modification. Public raw URLs are
inaccessible until the private repository is made public.
