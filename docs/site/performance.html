02 / what the numbers mean

Four different levers.

A larger ratio does not make two experiments comparable.

Implementation

Do the same work once.

Batch equivalent array and geometry operations. Keep the estimator, initialization, solver, precision and QC thresholds unchanged. Source guards retain upstream behavior when qualification does not match.

Native threads

Use existing compute capacity.

AMICO already supports multithreading. Configuring that capability is useful, but it is not a new NODDI algorithm. Thread budgets and hardware are part of the measurement.

Scheduling

Overlap independent jobs.

FW, NODDI and DKI can run in separate processes after their inputs are ready. Dependencies still apply; CPU and memory budgets may limit overlap. Default concurrency is one.

Python-port control

Name the real reference.

MK-Curve port improvements are compared with earlier Python computation, not author MATLAB. A language port and an original-author runtime comparison are different claims.

03 / still open

The boundary of the evidence.

These measurements describe specific Linux inputs and settings. They are not a substitute for independent scientific review.

  • Whole workflowNo matched old/new end-to-end percentage. Do not add savings or multiply ratios from overlapping stages.
  • GeneralizationRepeat complete-module pairs across more subjects and hardware. Single pairs have no confidence interval.
  • Long-task coverageA completed full-brain DKI pair, later default-QR MK-Curve timing and matched CSD/ACT/SIFT2 comparison remain open.
  • Other methodsNo matched original-author runtime improvement is claimed for DDSeg, DDParcel, SAF, UKF or TractCloud. Shared DDSurfer surface mapping is attributed to upstream, not presented as a new plugin algorithm.
  • Validity and platformsWMA small-bundle sampling and invalid fit voxels still require their own review. Native Windows/macOS scientific timing is not certified.
  • Next experimentA local persistent-model worker could reuse weights across subjects. It is proposed, not implemented or benchmarked; no benefit is claimed.
