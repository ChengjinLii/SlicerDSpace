3D Slicer module · Diffusion MRI

Brain anatomy from diffusion MRI, inside 3D Slicer.

SlicerDDSurfer builds tissue labels, brain regions and cortical surfaces from diffusion MRI, with no T1-weighted scan at analysis time. It also maps microstructure, traces white-matter pathways and builds structural connectomes.

The idea

Anatomy from the diffusion scan itself.

Diffusion studies have usually needed a second, T1-weighted scan, registered into diffusion space.

SlicerDDSurfer works from the diffusion scan. DDSeg labels tissue, DDParcel labels regions and DDSurfer builds white and pial surfaces, all in native diffusion space.

Canonical input

sub-01/
  input/
    data.nii.gz
    bvals
    bvecs
    nodif_brain_mask.nii.gz   # optional; generation needs a supported backend

DWI and mask must share one voxel grid.

‘No T1-weighted scan’ describes analysis time. The models were trained with labels derived from T1-weighted MRI.

One subject, one space

From one diffusion dataset to seven kinds of result.

Data: EDDEN sub-01 (OpenNeuro ds004666, CC0), AVG_mag series. The series averages five repeated acquisitions, so its SNR is higher than a typical single scan. Six images come from the film’s run (b = 0 and b ≈ 1000; 117 of 297 volumes). The others come from runs of 23 October 2026 on the same Mac: UKF on the same input; the multi-shell methods on b = 0, 1000 and 2000 (207 of 297 volumes).

Products

Choosing routes

Which route when.

In 3D Slicer

One 3D Slicer module, with QC and a record of every run.

A run in six steps

  1. Open SlicerDDSurfer and choose English or Chinese.
  2. Enter the Subject ID, the subject root and, optionally, an output directory.
  3. Tick only the products you need.
  4. Choose each product’s algorithm. Prepare dependencies in Environment; set detailed parameters in Advanced settings.
  5. Click Run SlicerDDSurfer. Missing inputs turn red; the log says what to correct.
  6. Key results of successful stages load into the scene. Review QC, reload, replace or clear them in Advanced settings › Results and QC.

From the command line

Check inputs and environment without running anything:

shell
python3 run_subject_pipeline.py --subject-root /path/to/sub-01 --targets validation,microstructure --microstructure-stages dti --doctor

Use --plan instead of --doctor to write a run plan.

Get started

Install from source.

The repository is private during pre-release; you need access to clone it or open its links.

  1. Stage the extension

    bash
    git clone https://github.com/ChengjinLii/SlicerDDSurfer.git
cd SlicerDDSurfer
python3 scripts/stage_slicer_extension.py \
  --install-root ~/SlicerDDSurfer-extension --link-mode copy --clean

    Set --slicer-version to your Slicer version. This is a source install, not an official CPack release.

  2. Add the module path

    In Edit › Application Settings › Modules, add the expanded absolute path of ~/SlicerDDSurfer-extension/SlicerDDSurfer/lib/Slicer-5.10/qt-scripted-modules to Additional module paths and restart Slicer. GUI validation uses Slicer 5.10.

  3. Add the extensions your routes need

    Install SlicerDMRI and PyTorch from Slicer’s Extension Manager.

  4. Get the model files

    Read the asset terms, then download only the profile you need to a writable folder outside the checkout:

    bash
    python3 scripts/download_model_assets.py --profile surface \
  --asset-root ~/SlicerDDSurfer-model-assets --source url \
  --source-id slicerdsurfer_models_git

    Availability and SHA256 verification do not establish redistribution rights.

  5. Prepare the input

    Use the canonical layout under Idea. Gradients must match the DWI; motion-corrected DWI needs corrected gradients.
