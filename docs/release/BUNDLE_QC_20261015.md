## Why Earlier Green States Were Insufficient

**CST follow-up:** [The dedicated CST investigation](WMQL_CST_20261015.md) distinguishes
the published/tutorial endpoint rule from the legacy repository crossing/exclusion
rule. Current paired default QC v4 produces CST 170/363 with source checks passed;
the legacy query remains failed. Earlier counts below are retained as historical evidence.

The WMQL wrapper checked requested filenames, complete decoding and non-empty
outputs, but a one-streamline AF satisfied that contract. Its scientific warning
did not change `completed`; a unit fixture even expected four one-line outputs
to succeed. The result browser also counted a recorded `completed` as passed QC.
This was an acceptance-policy defect, not evidence of validated AF anatomy.

WMA originally relied on file counts/launch success. The October 13 audit had
already rejected the old 100307 products under a stricter coverage policy. Old
green records must not override that later audit. The previous tests did not
establish input suitability or manual anatomical validation.

The pinned WMA registration/clustering CLI uses a default 40 mm preprocessing

the only factor: these runs also differ in pipeline/anatomy versions, so this
comparison is not a controlled single-variable causal experiment. The current

but no 3001–3035/4001–4035 regional WM labels. Streamline endpoints are in the
native atlas field of view. The bundled cortical-endpoint candidates are not
equivalent to the author's anatomical queries involving regional WM and spatial
relations. We did not dilate labels, move endpoints or synthesize missing fibers.

## New Acceptance Policy

The initial QC version 3 introduced at least 20 streamlines per requested bundle and
records query SHA256. Single-line fixtures now test failure, not success.
Old QC versions and changed queries cannot be silently reused.
Current QC v4 additionally freezes and hashes recursive imports and identifies
the actual CST definition; its changes do not relax the sampling threshold.

WMA retains its existing minimum 73 decoded/55 non-empty tract policy and also
records per-tract counts. Bilateral AF/CST and CC4 must exist with at least 20
streamlines each. These are **local adult whole-brain ORG sampling/identity
sanity checks**, not author accuracy thresholds, power analyses or guarantees
that absent fibers indicate disease. Selected/lesional/partial tractograms may
legitimately fail this full-coverage acceptance contract.

Both wrappers explicitly record automatic-QC status and pending manual review;
`quantification_eligible` remains false until scientific review outside this
automatic check. UI result selection and QC summaries independently apply the
current policy to old records. A successful process cannot restore an old
green state. Failure products and original research inputs are preserved.

## WMA Rerun

A fresh official rigid/affine WMA run on the current 50,000-track dynamic-seeded
100307 input is isolated in `ignore/validation/bundle_fix_20261015/wma_dynamic50k`.
The rerun completed in **2071.373 s**. All 74 VTP files decoded; 64 were non-empty,
but CST L/R contained only **1/0** tracks (AF 125/109, CC4 334). The current
major-tract contract therefore **fails**, despite improved aggregate coverage.
All 13,049 assigned tracks matched the source, with maximum coordinate error
below 0.001 mm. Original green metadata was archived and revalidated as failed;
track data were not altered. No successful WMA100307 quantification is claimed.
Old 100307 results (45/74 and 34/74 non-empty) remain rejected.

The separate 149741 UKF result was independently redecoded and revalidated under
the current contract; its geometry/source membership and major-tract sampling
passed. This is not a fresh extraction or proof that CSD/UKF inputs are interchangeable.
