## 复现与修复

对修改前代码运行真实 Slicer GUI 测试，复现了四项失败：返回模块后未保存的场景参数
被覆盖；载入场景后保存的参数被全局最近设置/默认值替换；新日志强制滚到底部，打断
阅读；输入为空时，依赖检查成功仍显示绿色就绪状态。

修复后同一测试的五项断言全部通过，包括原有的“已经在底部时继续跟随新日志”。

现在仅对新建/重置的空参数节点应用一次用户默认设置。已有场景及载入的场景优先保留
参数，旧版场景没有新标记也不会被覆盖。恢复完成后再连接 GUI，避免反复同步；同时
避免重入模块时重复删除观察器。机器相关外部依赖设置仍与场景分析参数分开。

找到输入文件结构时，改为中性提示“点击运行时将检查依赖”。依赖检查成功不会掩盖
缺少输入或未选择分析任务。检查报告目录无法解析时，返回明确的行内错误，不启动
工作进程；该异常路径已有单元测试。无活动任务时，Run 按钮仍可点击并进行校验。

## 日志写入实测

原来每行日志都单独跨 PythonQt 调用一次。现在普通非空行输出块一次写入，保留分段、
HTML 转义、严重程度配色及用户的滚动位置。边界对照发现 Qt 会合并空 HTML 段落，
因此含空行的输出块保留原逐行路径，不以丢失空行为代价提速。

| 每块行数 | 原实现中位数 | 批量写入中位数 | 局部加速 |
| --- | --- | --- | --- |
| 500 | 28.07 ms | 9.00 ms | 3.12 倍 |
| 2,000 | 115.02 ms | 35.29 ms | 3.26 倍 |

同一真实 Slicer/Qt 进程中交替测试两种实现，预热后各重复七次。两者均使用隐藏控件，
同样排除事件处理时间；纯文本与段落数量完全一致，并通过空行、空白、转义及中文
文本的附加对照。它只衡量 **GUI 日志插入开销**，
不是可见帧延迟、MRI 算法加速或完整流程加速。旧实现快照的 SHA256 与机器记录中的
基础提交一致。

## 输入目录后续优化

原来修改无关的算法参数，也会重复识别输入目录、读取 DICOM 文件头。现在仅对昂贵
识别分支复用结果：每个窗口最多一条记录，两次检查之间最多复用 1 秒；路径、被试或
浅层文件状态变化时失效。针对目录时间戳可能漏掉快速变化的情况，直接检查 DWI、
bvals、bvecs 文件状态。标准 DWI 和旧式配准目录仍即时识别，不额外计算缓存指纹。
深层 DICOM 内容变化可能要等过期后的下一次界面检查才更新显示，不是后台自动轮询。

手动验证和点击 Run 均强制重新识别。后台的无缓存检查、DICOM 转换凭据校验、
梯度及内容验证、科学 QC 均未修改。另外，依赖检查现在先解析父目录下实际被试目录，
再判断其脑掩膜是否已存在，避免错误判断掩膜生成依赖。

| 连续识别目录 20 次 | 原实现中位数 | GUI 路径中位数 | 含义 |
| --- | --- | --- | --- |
| 合成 DICOM 目录，129 个文件头候选 | 119.70 ms | 9.41 ms | 重复识别开销降低至约 1/12.72 |
| 标准 DWI 目录 | 2.27 ms | 2.58 ms | 每次约增加 0.015 ms，不宣称提速 |

同一真实 Slicer 进程内交替顺序，预热后各七次，识别结果完全一致。DICOM 夹具只有
可识别文件头，不是完整临床采集；不衡量转换耗时、科学算法或整条流程加速。
首个试验的通用缓存让标准目录检查变为 3.61 ms/20 次，最终设计移除了这部分额外
指纹开销。首轮与最终测量原始记录均保留在本地，没有隐藏不利结果。

新增六项真实 GUI 断言全部通过：首次 129 次探测后修改参数不再读头；DICOM 缺掩膜
仍要求生成依赖；嵌套文件头原地损坏后点击 Run，在环境准备前即拒绝启动；可发现
父目录下被试已有的掩膜；移除掩膜立即要求生成依赖；移除 bvals 无需等待缓存到期
即被拒绝。

最终重跑七个 GUI 场景：输入检查、场景状态、紧凑布局、Extension Manager 安装及
Self Tests、场景结果管理与后台取消、算法多选、异步环境检查。隔离设置、禁用网络，
全部通过。Python 回归 **1,336 项：1,331 通过、5 跳过、0 失败**。staging 安装包
**470 个运行时文件**匹配，包含新增辅助模块；不是新一轮 SDK/CPack 构建。
日志及设置保留在 `ignore/validation/gui_inputs_20261023/`，
[输入检查记录](benchmarks/gui_input_inspection_20261023.json)保存哈希、计时和测试数量。

首次冷扫描 DICOM、大体积 MRML 加载仍可能占用主线程。这些 GUI 测试不代表所有
科学算法及所有平台均已验收，也未重启现有交互会话。
