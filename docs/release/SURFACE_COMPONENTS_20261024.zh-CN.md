## 集成行为

GUI 与 CLI 共用可选组件目录和个人激活文件配置。显式组件目录优先；否则保留已有
FreeSurfer，或查找按构建配方区分的用户缓存。独立子进程验证运行包，个人激活文件
缺失单独提示。**检查和运行分析均不会隐式下载或编译。**

“准备所选分析环境”明确获得源码／数据条款同意后，才在后台编译，可取消。
Git、C/C++ 编译器、系统开发库和 CMake >=3.24,<4 须事先可用；不自动安装系统编译器，
不修改 Slicer Python，不获取个人激活文件。GUI 确认说明这些条件，CLI 还可指定 CMake。

29,657,074 字节的图谱压缩包作为可选资源从固定 DDSurfer 提交下载并校验 SHA256，
存放在扩展目录外。不打包从完整套件提取的二进制，也不把个人激活文件加入扩展或模型仓库。
后处理缓存记录组件身份，切换显式组件目录不会复用其他运行环境的“已完成”状态。
历史 STL/shell 和 SynthStrip 的依赖保持独立，见[配置说明](../setup/SURFACE_COMPONENTS.zh-CN.md)。

## 实际验证

| 检查 | 结果 | 范围 |
| --- | --- | --- |
| 可选图谱获取 | 真实下载及 SHA256 校验通过 | 固定上游 URL，不声称已上传模型镜像 |
| 独立源码编译 | 七个命令、67 项清单文件、89,406,503 字节，组件校验通过 | 新构建目录，固定 Git 源码和依赖源码包已缓存，禁网，隐藏完整套件 |
| 从头执行科学适配器 | 100307 左半球、种子 1234；139 项产物数值和结构与已有完整 FreeSurfer 参照一致 | 652.261 秒，自动完整性 QC 通过，人工解剖审核待完成 |
| 原生 Slicer GUI | 组件识别、紧凑中英文布局、异步环境检查、Extension Manager 安装通过 | 独立设置、组件和代码只读、禁网 |
| 安装包资源 | 491 项运行时文件匹配 | staging 生成的包，不是本轮 SDK/CPack 构建 |
| Python 回归 | 1,348 项：1,343 通过、5 跳过、0 失败，75.935 秒 | 跳过项不算通过，未重跑全部科学后端 |

科学对照使用的是上游已从源码构建的运行包；随后本项目在新目录独立编译了同一固定
源码／配方，并用新组件运行最终 GUI 验收。没有再对第二个组件目录重跑 139 项科学对照，
这两部分证据不混为一谈。652.261 秒只是一次左半球处理耗时，不是加速比例、双半球
或完整工作流测速。

GUI 首轮真实暴露了误报缺失：隔离环境后直接启动 Slicer 的 `python-real`，无法找到
标准库。桥接代码已改为使用同目录 `PythonSlicer` 启动器，修复后相同检查通过；
失败记录保留。最终 GUI 准备测试取消确认弹窗，并确认没有生成运行包；实际编译
由独立 CLI 测试覆盖，不冒充已经完成 GUI 内编译。
