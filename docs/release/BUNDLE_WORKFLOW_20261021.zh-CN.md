## 结论与边界

不能把“后端成功退出”“自动文件／采样检查通过”和“专家确认解剖正确”混为一谈。
本轮没有降低 WMQL/WMA 门槛、复制流线、修改网络权重或覆盖历史失败。
以下结果仍需人工解剖复核，不能直接宣称所有被试、所有追踪协议均适合可靠定量。

WMA 是保存结果重审，不是本轮重新跑了完整配准。TractCloud 两次运行的网络、权重、
种子与批量参数相同，输入不同；42 是 TractCloud 自己的输出分组，不能与 WMA 的 74
个左右分侧束直接比较。历史 50k CSD 是适配器／重复性测试输入，不是新版 ACT 验收。
`ddparcel_act` 是明确记录的适配定义，不是未经修改的作者 AF/CST 查询。

TractCloud 新增 **20 条流线的本地采样筛查**与逐束数量记录，筛查不是作者性能指标或
解剖金标准。文件解码通过但有低采样束时，界面 QC 记为 warning，不笼统标为全部通过；
低采样束列入 `sampling_screen.excluded_from_quantification`。
`quantification_eligible=false` 保留人工复核边界。来源归属与互斥分配另有独立审计，
不能仅凭 `automatic_qc_passed` 的文件／几何检查推断它们已经执行。

## 自动运行与修复

默认仍为 CSD/ACT 追踪和 WMQL 束提取；不会默认运行所有后端。
在 Advanced 选择 **UKF + WMA** 时，自动完成输入转换、作者 UKF CLI 调用、
VTK/TRK 导出与 WMA 衔接。用户不需要先到另一个模块追踪，再手动导入文件。
UKFTractography/SlicerDMRI 首次安装、WMA 后端及 ORG 图谱准备仍是依赖条件，
不能在缺少这些资源时声称零配置可运行。

本轮修复：

- GUI 显式向后台传递 **UKF 和 DWIConvert 两个 CLI 路径**，支持安装目录外的扩展；转换器和追踪器分别使用自己的动态库环境。
- TractCloud 纳入与 WMQL/WMA 共用的结果加载 QC 门禁；显式失败、错误信息或旧版无明确 QC 的记录不再被当成成功结果加载。
- WMA 缓存复用也检查当前 QC 版本、显式通过标志和逐束采样，不仅查看目录中是否有输出。
- 编排层的 QC 失败不再被后端的 `completed` 覆盖；后端失败也不能被外层成功状态提升。
- DTI 确定性追踪接入 TractCloud 时自动导出完整 RAS VTK，禁止误找旧 CSD 或其他运行结果。
- VTK 转换逐条逐点验证，坐标容差 0.0001 mm；源／导出 SHA256 匹配才复用，不抽样、不补流线，也不是显示预览。

这些是工作流、缓存和质量控制增强，不是重新实现 UKF/WMA/TractCloud，也不构成
原分类算法提速或解剖精度提升的证据。显式已有流线覆盖输入仍保留在高级配置／CLI。
WMA 缺少适用输入时提示选择 UKF 自动路线，不静默把 CSD 改名或替换算法。

## 验证记录

单元回归 **1,189 项，1,184 通过、5 跳过、0 失败**。包含 GUI 到后台参数传递、
旧 QC 拒绝、显式失败优先、DTI 同运行输入绑定和无损转换／缓存失效测试。

隔离 Slicer 5.10 中，UKF 控件和真实作者 CLI 合成张量场测试通过：1,728 条流线、
100% 掩膜重合、FA／张量数组与 VTK/TRK 坐标核验通过。首次隔离启动漏掉 SlicerDMRI
动态库路径，纤维加载失败；补全测试进程路径后重新通过，原失败保留在 `native/`。
这不是算法失败，也不是新安装 Extension Manager UKF 包的验收。

同一隔离 Slicer 中，三被试 WMQL 的 12 个束、WMA 的 74 个束和本次 UKF 输入
TractCloud 的 42 个束，共 **128 个真实文件**全部加载通过。WMQL 的最大坐标差为
0.00000763 mm，WMA／TractCloud 为 0；均低于 0.001 mm 验收容差。旧 TractCloud
QC 被拒绝加载、失败时撤下自动节点、保留用户手动节点的场景测试也通过。

TractCloud UKF 输入的完整本次调用为 **104.39 s**，独立解码／来源审计为 **16.97 s**，
不含 UKF 追踪、模型下载与 Slicer 启动。服务器同时有其他 GPU 任务，不能将此数值与
历史 50k 输入耗时解释为优化前后加速比。

原始日志与独立审计保存在 `ignore/validation/bundles_review_20261021/`；机器可读摘要
记录来源哈希、代码哈希、各束数量、审计检查及隔离 Slicer 报告。旧失败未更新为通过。
