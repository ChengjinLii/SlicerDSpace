## Finding

The earlier description of `freesurfer_queries.qry` as the unique "author-original
CST" was inaccurate. Its crossing/exclusion CST differs from the endpoint rule in
the [author tutorial](https://tract-querier.readthedocs.io/en/latest/example_script.html)
and [2016 paper, Table 4](https://doi.org/10.1007/s00429-015-1179-4).
The default now explicitly implements that published endpoint definition with the
original FreeSurfer cortical/WM aliases. AF remains a separately identified
DDParcel-adapted endpoint candidate. Neither definition nor sampling QC is an
expert anatomical certification.

## Exact Cause

The unmodified author parser and spatial index reproduced the original 0/11 result:

- A region must contain at least 2% of a streamline's sampled **points** to count as a crossing. This is not the endpoint test or an exact physical-length proportion.
- Of the 133/304 endpoint-selected CST tracks with the newer atlas, 126/280 failed the brainstem crossing threshold; 38/131 failed the cortical crossing test. These counts overlap.
- Left precentral/postcentral crossing branches each retained only four tracks, then the thalamus exclusion removed all of them. Right branches went from 12/11 to 7/4.
- No coordinate flip, endpoint motion, atlas dilation or threshold relaxation was used. The independently traced sets exactly matched the original parser outputs.

The initial follow-up combined the September tractogram with a newer October
DDParcel atlas. A paired control using the atlas recorded for the original ACT
preparation still failed the legacy query. Thus this mismatch affected counts but
was not the sole cause of the sparse legacy CST.

## Implementation

- Added `CST_WMQL2016.qry`; default CST uses the same original region aliases, supporting genuine regional WM labels when available.
- QC v4 records query-specific provenance rather than calling every external query a DDParcel adaptation.
- Source and staged query imports are recursively hashed. All platforms run against copied imports; custom-directory precedence is preserved and stale snapshots refreshed.
- Published-definition attribution also requires the original regional-alias file. A copied endpoint statement with modified aliases is not certified equivalent.
- Changed queries/imports or inputs during execution fail the run. Changed imported definitions invalidate resume; old QC cannot silently supply current success.
- Retained the 20-streamline sampling gate and `quantification_eligible=false`. Legacy failures are not renamed or overwritten.

Real isolated Slicer testing checks current-QC selection, rejection of the failed
legacy result, native loading of both CSTs and coordinate preservation. Preview
images are diagnostic, not publication evidence of anatomical accuracy.

Current regression: **1,001 tests, 1,000 passed and one explicit skip**. Active
documentation link/style checks passed for 52 files. The test log is retained as
`ignore/validation/wmql_cst_20261015/regression_tests.log`. Real Slicer tests use
an isolated installation and settings without changing the active user session;
package resources, native fiber reading and current/legacy QC selection passed.
The final installation record is `gui_current/gui_acceptance.json` (14.6 s).
One `gui_verified/` invocation omitted the switch to skip unrelated DTI fitting
and failed on a missing test-configuration field. That failure is retained and
is not counted as successful product acceptance.

## Evidence And Boundary

query snapshots, the definition-parity report, independent source audit and Slicer
records. Original DWI, label images and streamlines were not edited. No new

trajectory. Expert review of the motor pathway, individual anatomy and any
