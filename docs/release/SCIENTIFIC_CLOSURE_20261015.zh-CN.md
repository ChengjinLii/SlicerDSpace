独立审计确认 95,755 条输出均匹配源几何，自动完整性／采样检查通过，人工解剖
审核仍待完成。提取及验收实测 6510.590 秒（108.5 分钟），不含 UKF 追踪；
独立审计记录中的等待时长不能误作提取耗时。
[图谱官方说明](https://dmri.slicer.org/atlases/)写明其构建使用 UKF，同时允许 RAS
streamline 输入；不能错误表述为 WMA 只支持 UKF。

`SLICER_HOME` 定位并验证运行时，清理继承的 Python 覆盖项，记录实际解释器；直接

## 全脑 MK-Curve

| 项目 | 实测结果 |
| --- | --- |
| 原始脑掩膜 | 740,916 体素全部计算 |
| 拟合协议 | 完整 b≈1000／2000 壳层，18 个 b0 求均值；预声明上限 2500 s/mm² 排除 90 个高 b 体积 |
| synthetic-b0 网格 | 202 个采样，保留作者式校正 |
| 耗时 | 989.384 秒；16 CPU worker；有界分块 |
| 发生校正 | 320,556 体素 |
| 校正后有效 | 736,294 体素，99.376% |
| 常规参考对照 | 128 个确定性真实体素，比较 QR 系数、原始参数、完整曲线及判定 |
| 无效体素专项对照 | 额外 128 个无效体素，参考 QR 复现参数和有效性判定 |

可选 batched WLLS 与原参考 QR 解同一加权目标，病态系统回退到 QR。没有平滑、
补洞或截断原始参数。全网格、输入哈希和参考对照通过，但原拟合记录的“全部体素
有效”标志仍保留为 **false**，不与执行成功或完整性通过混淆。

4622 个无效体素都有有限参数，主要重叠原因是 RK 超出 [0,3]（3508 个）、MK 大于
3（683 个）、AD 大于 0.005 mm²/s（643 个）。DDSeg 预测标签中，2510 个位于 WM、
61 个位于 GM、2051 个位于 CSF；只有 1360 个位于脑掩膜边界 2 mm 内。因此不能把
这些位置笼统说成正常 CSF 空洞，应继续标为不可可靠定量，保留原值和显式有效掩膜。
无约束拟合的限制不能靠美化图像解决。

曲线对照使用明确的相对／绝对容差；极端未校正曲线数值很大时，即使相对误差通过，
绝对差仍可能很大。本报告不声称所有数值都有极小绝对误差，也不是全脑 MATLAB 重跑。

### 失败分支补查

最终复核又发现并修复了三项界面／报告缺陷：

- 整个束任务被拒绝时，拒绝记录不带文件路径，自动加载器却按文件记录索引而抛出
  `KeyError`。现在按当前运行／失败产品撤下自动节点，保留手动加载和用户数据。
  自动复用也不再把手动节点改标为自动节点；源文件更新时保留旧手动复核节点，
  只替换自动预览。
- 旧 `automatic_qc_passed=true` 可能覆盖明确失败状态／子检查／错误。现在失败优先；
  失败任务不能借用旧通过 QC，失败／取消任务对应的旧自动预览也会撤下。
- WMA 审计原先把不适用的 TractCloud 互斥分配、WMQL 端点检查记为 true。现在只统计
  适用检查，其余写入 `checks_not_run`。新 WMA、作者旧查询 WMQL 重审仍通过实际
  来源／几何／采样检查；作者 CST 条件的专项复算证据仍独立保留。
