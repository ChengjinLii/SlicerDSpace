## 定量排除验证

全脑 MK-Curve 的 740916 个脑内体素中，736294 个符合既定有效性标准，4622 个
（0.624%）不符合。原始参数图保留这些估计，定量统计排除它们；不填洞、不平滑、
不把异常值裁切成合法值，也不将它们一概解释成正常脑脊液。

`scripts/audit_regional_validity.py` 通过生产代码导出区域表，再从原始参数图以
float64 独立计算数量及统计量。使用本轮新生成的 DDParcel 图谱，**101 个脑区、
7 项指标、2828 次统计对照通过**，输入 SHA256 前后不变。第二次审计耗时
17.539 秒，不含拟合。证据位于：

```text
ignore/validation/act_v3_completion_20261016/mkcurve_quantification_v2/
  acceptance.json
  regional_mkcurve.csv
  regional_mkcurve.json
```

`automatic_quantitative_exclusion_qc_passed=true` 仅表示排除及区域统计正确；
原始拟合的 `automatic_qc_passed=false` 仍表示并非所有脑内体素均有效，人工审核待完成。

生产区域表现为每个指标分别记录有效数量、排除数量及覆盖率，并保留解剖 ROI
总数。空估计使用 JSON null／CSV 空单元格，不写成测量值 0，也不删除整个脑区。
FW 组织有效性掩膜显式传递，不再被“非零即有效”的备用规则覆盖。掩膜必须二值、
有限且处于原生网格；NODDI 的组织有效性用于 NDI／ODI，不套用到 IsoVF 本身。

恢复运行会拒绝旧表、变化的图谱／参数图／掩膜、缺少必要 DTI 指标的表，以及
CSV／JSON 不一致的导出。从合格参数图重建统计不等于重新拟合模型。定量掩膜
与连续显示规则保持分离。

之后增加的只读审计不调用导出器，而是从原图重新核对现有表格。MK-Curve 的
101 个脑区、7 项指标共 **4949 次计数／估计对照通过**。图谱有标签的 553750
个体素中，551094 个满足 MK-Curve 有效性；这是图谱范围内数量，不是上述全脑
总数。证据为同一验证目录下的 `mkcurve_statistics_readonly/acceptance.json`。

原生图谱有 12 个带标签体素位于实际拟合脑掩膜之外。生产统计现与拟合掩膜取交集，
但仍保留解剖 ROI 总数。从真实 DTI／NODDI 输出生成的当前表独立通过 **101 个
脑区、11 项指标、7777 次对照**。DTI 和 IsoVF 使用 553738 个有标签且在拟合
脑掩膜内的体素；NDI／ODI 再应用组织有效性，使用 544927 个。参数图未变。
证据为 `regional_current_independent/acceptance.json`。联合科学审计已加入区域表
数值核验；测试特意构造 CSV／JSON 相互一致但数值错误的表，确保匹配的缓存记录
不能代替与原图一致。

## 新版 CSD 路线

隔离的真实 Slicer GUI 使用 `a48fc95` 打包快照，输出到
`act_v3_completion_20261016/products`。HCP 输入、脑掩膜及匹配的 SlicerDMRI
原生 DTI 缓存复用，因此不能当作原始预处理或 DTI 拟合的全新计时。DDSeg、
DDParcel 与原生表面已完成；首次表面后处理耗时 746.742 秒，DTI 参数导出及
区域统计耗时 8.178 秒。新 NODDI 拟合耗时 424.115 秒，自动 QC 通过；
ACT v3 的新版 CSD 已完成 100 万条追踪、SIFT2 和格式／几何检查，耗时 1892.7 秒。

本轮配置为 ACT v3、100 万条 iFOD2、SIFT2、WMQL、流线数及加权连接组，
追踪／SIFT2 使用 8 线程及正常动态播种。没有以单线程局部诊断或降低采样门槛替代。

WMA 在上述前序门禁通过后使用这份新 TCK，官方 ORG 提取耗时 **4756.080 秒
（79.27 分钟）**，另有 2350.282 秒等待 CSD，不混入算法计时。74 个束均非空，
AF 为 **1800／1301** 条，CST 为 **337／937** 条，CC4 为 **4868** 条。
独立有限坐标及来源流线归属检查通过，最大坐标差 7.63e-6 mm，TCK 与 CSD
清单／QC 哈希未变。

这不表示所有束都可定量。五个小束仍低于 20 条的采样参考：左 CR-P（5）、
双侧 EC（8／7）、右 EmC（7）及右 Intra-CBLM-PaT（5）。既定主要束门禁不对
这些小束作可靠性认证；人工审核及定量资格仍待确认，旧 CST 3／4 条失败记录保留。

同一份新源数据上的 WMQL 存在明确的**定义相关失败**：

| 显式查询 | AF 左／右 | CST 左／右 | 提取耗时 | 自动结果 |
| --- | ---: | ---: | ---: | --- |
| 内置论文 CST 端点定义 | 61／54 | 13／18 | 90.936 秒 | 失败，20 条门槛不变 |
| 未修改的作者仓库穿行／排除规则 | 70／28 | 154／311 | 85.224 秒 | 采样及独立来源检查通过 |

因此原始 GUI 全流程终态为 **FAIL**，不是科学验收全部完成。作者仓库规则是另行
标明的对照，不自动回退，也不替换失败的端点定义。逐谓词复算重现两套数量，
保存的作者规则结果与应选流线在 0.001 mm 内逐条、一一对应。字节不完全相同来自
ASCII 导出精度，最大坐标差为 1.53e-5 mm，不是修改了走行。审核比较全曲线、
数量和重复分配，不只检查端点。第一次纯字节比较的诊断仍保留；修正后的几何
对照记录为 `wmql_legacy_predicates_geometry/predicate_trace.json`。

来源为[作者查询固定版本](https://github.com/demianw/tract_querier/blob/5c69c594d489859e08485110678dca7f6f4cba40/tract_querier/data/freesurfer_queries.qry)，
查询及脑区别名的字节均与该上游版本一致。安装副本曾因缺少开发目录而误标原始
别名，现改用固定上游 SHA256 验证。每次运行独立保存查询及导入快照，避免重跑
覆盖历史执行定义。这两处修改不降低采样门槛，也不改变默认解剖规则。

真实 superbuild 已完成，包括 VTK、ITK、CTK、SimpleITK 及 Slicer。缺失的

sysroot，不安装到用户的运行环境。已复现 Qt／C++ ABI 链接不兼容，并使隔离的
CTK launcher 编译通过。扩展配置及构建已成功，但首次 CTest 暴露了无显示环境、
测试依赖缺失及主模块实际运行零项测试的问题，失败尝试保留。现补充真正的原生
参数／逻辑测试，以及拒绝零测试假成功的门禁。后端单元测试使用显式独立 Python，
通用／原生模块测试仍在真实 SDK Slicer 内执行。修正后的运行通过 **128 项
CTest（126 个独立后端测试套件及2个原生 Slicer 测试套件）**，耗时 108.65 秒。
CPack 生成真实 TGZ，460 个运行资源哈希与源码一致，无缺失、额外或不安全条目。

使用该真实包而非 staging 替代品，Extension Manager 隔离安装、用户／版本设置
隔离和安装目录导入均通过。后续原生测试通过：失败 QC 拒绝／自动预览撤回、手动
节点所有权、5个 WMA 产品（9243条）、2个作者 WMQL CST（465条）、CST 渲染
及 GUI DTI 缓存／区域表恢复加载。WMQL TRK 显示转换坐标误差不超过 7.63e-6 mm。
安装、束套件和缓存 DTI GUI 分别耗时 13.836、115.635、24.200 秒。

官方 Slicer 二进制、SlicerDMRI 和科学依赖已预配置；设置与扩展安装为空白隔离。
这不证明空白机器依赖安装、全脑 DTI 全新拟合、所有算法或专家解剖均通过。
失败的端点 WMQL 仍被排除。
