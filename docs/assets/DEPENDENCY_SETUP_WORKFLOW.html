SlicerDDSurfer setup guide

依赖安装与模型资产下载流程

SlicerDDSurfer 将依赖分成三类处理：Python 包安装到 Slicer Python，外部软件选择已有安装路径或生成安装说明，模型权重下载到用户选择的资产目录。

Python packages安装到 Slicer Python 或用户指定 Python/conda。
External tools选择本地已有路径，不静默修改系统。
Model assets下载/校验到统一 asset root。

三类依赖的区别

这三类资源都可以由脚本辅助处理，但不能用同一种“填写安装路径”的语义。Python 包的路径指向 解释器/环境；外部软件的路径指向已有软件安装位置；模型权重的路径指向 可写的资产缓存目录。

Auto install

Python 包

目标是一个 Python 环境，而不是文件夹。默认目标是当前 Slicer Python，例如 PythonSlicer。

  • UI 字段：Python executable 或 Python/conda environment
  • 按钮：Install
  • 动作：运行 python -m pip install ...
Path / setup

外部软件

目标是用户已经安装好的软件目录。插件会自动扫描环境变量、PATH 和常见路径，但不会静默安装系统软件。

  • MRtrix3/FSL：通常选择 bin 目录
  • FreeSurfer：选择 FREESURFER_HOME
  • WMA/TractCloud：选择 checkout、Python 或 data/model 目录
Download

模型权重

目标是统一资产根目录，插件按 manifest 下载并校验 DDSurfer、DDSeg 和 DDParcel 所需权重/模板。

  • UI 字段：Model assets root
  • 按钮：Download / choose path
  • 环境变量：SLICERDDSURFER_MODEL_ASSETS_DIR

为什么外部软件仍要填路径

MRtrix3、FSL、FreeSurfer、WhiteMatterAnalysis 和 TractCloud 可以提供安装脚本或安装说明，但默认运行时仍优先要求用户选择或确认路径。 这样做是为了避免插件在用户机器上静默修改系统环境。

资源类型 脚本可自动做什么 为什么还需要路径
Python 包 调用所选 Python 的 pip 安装缺失包，例如 tract_querier。 路径用于确定安装到哪个 Python，而不是选择包文件夹。
外部软件 生成平台相关安装建议；在用户确认后可运行 conda、brew、apt 或源码安装脚本。 不同系统、权限、license 和已有实验环境差异很大；路径用于绑定已安装工具并避免覆盖系统。
模型权重 按 manifest 从 GitHub/Hugging Face/Zenodo mirror 下载，校验 checksum，并记录版本。 路径是资产缓存根目录，用户可放在共享盘、项目盘或个人缓存，不建议放进 Slicer 插件代码目录。

推荐 UI 流程

打开依赖检查

点击 Check environment dependencies，先让插件扫描已保存路径、环境变量、PATH 和常见目录。

查看缺失项

弹窗会列出缺失依赖，并按 Python、模型资产、外部工具区分按钮。

自动处理

点击 Install/download auto items，自动安装 Python 包，并为模型资产选择目录后下载/校验。

单项处理

每个缺失项右侧也有按钮，可单独安装 Python 包、下载模型，或选择已有外部软件路径。

重新检查

路径保存后自动 rerun preflight；重启 Slicer 后会从 user settings 恢复。

按钮语义

按钮 出现位置 会做什么 不会做什么
Install Python 缺包行 安装到当前 Slicer Python 或指定 Python/conda。 不会安装 MRtrix3、FSL、FreeSurfer 等系统工具。
Download / choose path 模型资源缺失行 弹出目录选择，保存 Model assets root，下载并 checksum 校验模型资产。 不会把权重写进 Slicer 插件代码目录，除非用户显式选择该目录。
Choose path / setup 外部软件缺失行 弹出路径选择并保存到 Slicer user settings；未选择时显示安装说明。 不会静默 apt/brew/conda 安装系统软件，不会覆盖用户已有环境。

命令行等价操作

模型资产建议下载到用户目录或共享缓存：

python3 scripts/download_model_assets.py \
  --profile core \
  --asset-root /data/shared/SlicerDDSurfer-model-assets \
  --source url \
  --source-id slicerdsurfer_models_git

只生成依赖计划，不修改系统：

python3 scripts/install_dependencies.py \
  --profile core \
  --model-assets-dir /data/shared/SlicerDDSurfer-model-assets \
  --output-dir install_plan

执行 Python 包安装时，安装目标仍是所选 Python：

python3 scripts/install_dependencies.py \
  --profile core \
  --python-executable /path/to/Slicer/bin/PythonSlicer \
  --execute
